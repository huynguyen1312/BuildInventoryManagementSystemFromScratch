- Manager
- Warehouse staff

## Use Cases

### Manager

- create a product
- update a product
- create a warehouse
- view stock levels
- view stock movement history

### Warehouse Staff

- stock in products
- stock out products
- view stock levels
  
## User Stories

1. As a manager, I want to create products so that items can be tracked in the inventory system.
2. As a manager, I want to create warehouses so that stock can be managed across different locations.
3. As a warehouse staff member, I want to stock in products so that inventory levels increase when new items arrive.
4. As a warehouse staff member, I want to stock out products so that inventory levels decrease when items leave the warehouse.
5. As a user, I want to view current stock levels so that I can see how many items are available in each warehouse.
6. As a user, I want to view stock movement history so that I can trace inventory changes over time.
