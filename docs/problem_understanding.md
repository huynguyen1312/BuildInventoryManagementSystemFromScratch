# Problem Understanding

## Context

Small shops or warehouses often manage inventory manually using Excel files or paper-based processes.
This can lead to inconsistent stock data, missing stock movement records, and errors in day-to-day inventory operations.

## Core Problem

There is no reliable backend system to manage products, warehouses, and stock movements in a structured and traceable way.

## Affected Users

The main users are:

- managers who need visibility into stock levels
- warehouse staff who handle stock in and stock out operations

## Goal of the System

The goal of this project is to build a backend API that helps manage inventory data in a simple and consistent way.

## Success Criteria

The system should:

- manage products and warehouses
- track current stock per warehouse
- record all stock in and stock out operations
- prevent negative stock

## Out of Scope

The initial version does not include:

- authentication and authorization
- warehouse transfer
- analytics dashboard
- CSV import/export
